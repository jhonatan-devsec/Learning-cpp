# 🎮 Tic Tac Toe in C++

A simple console-based Tic Tac Toe game for two players.

## How to Play

1. The game displays a 3x3 grid with coordinates (0-2)
2. Players take turns entering **row** and **column** separately
3. First to get 3 in a row (horizontal, vertical, or diagonal) wins!

### Input Format

- Enter **two numbers separated by a space**
- First number = row (0, 1, or 2)
- Second number = column (0, 1, or 2)

## Build & Run

```bash
g++ -o game game.cpp -std=c++11
./game
